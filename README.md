# Máquina de Rube Goldberg - Tarea de Desarrollo de Videojuegos

Proyecto interactivo desarrollado en **Unity**, diseñado como una máquina de Rube Goldberg en un entorno 3D, donde una serie de mecanismos encadenados interactúan mediante físicas, plataformas y personajes animados.

## 📋 Descripción del Proyecto
Este proyecto implementa una estructura compleja de causa y efecto. Utilizando los sistemas de físicas de Unity (Rigidbodies, colisionadores y fuerzas), una acción inicial desencadena una reacción en cadena a través de rampas, obstáculos y objetos en movimiento, ambientado con elementos visuales personalizados y un personaje animado en la escena.

## ⚙️ Características Principales
* **Simulación de Físicas:** Interacción precisa entre objetos, gravedad y colisiones para que la reacción en cadena funcione de manera fluida.
* **Sistema de Animación:** Integración de un controlador de animaciones (`Animator`) para dar vida a los personajes y elementos dinámicos dentro del escenario.
* **Diseño de Escenario 3D:** Construcción de plataformas, desniveles y estructuras modulares organizadas mediante una jerarquía limpia de GameObjects en Unity.

## 🛠️ Tecnologías Utilizadas
* **Motor gráfico:** Unity 6 (o versión compatible)
* **Lenguaje / Lógica:** Componentes nativos de Unity, físicas y controladores de animación.
* **Modelos y Activos:** Modelos 3D importados en formato FBX con texturas integradas.
